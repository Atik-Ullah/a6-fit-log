Project name : a6-fit-log.
Description : 
FitLog is a dark, no-nonsense workout library and gym companion. 
Users can browse workouts, view workout details, add exercises to today's plan, 
save workouts for later, and manage their workout plan.
Technologies : 
- Next.js
- React
- Tailwind CSS
- JavaScript
- React Toastify
- REST API
Feature : 
- this project built by next.js router .
- I am using reac-toastify in this project
- The application uses the FitLog workout API to load workout data.
- Browse workout exercises from the FitLog API
- Remove workouts from Today's Plan or Saved list
